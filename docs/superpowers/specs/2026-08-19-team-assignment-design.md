# 방탈출 조 편성 개편 + 단일 페이지 통합 설계

## 배경 / 목표

지금은 학생이 이름+학년을 직접 입력해 로그인하면 선생님이 "학생 배정" 탭에서 한 명씩(또는 자동버튼으로) 조를 배정해주는 구조다. 행사 규모가 커지면서 다음 세 가지를 바꾼다.

1. 학생 개인 로그인을 없애고, 관리자가 전체 학생 명단(구글시트 링크 또는 엑셀 파일)을 한 번에 업로드하면 학년이 고르게 섞이도록 조를 자동 편성한다. 상급학년부터 우선 배치하고 그 아래 학년 순서로 채운다.
2. 학생 화면은 "조 선택"만 하면 바로 입장하고, 관리자 로그인은 그 화면 아래에 붙는다.
3. `escape.html`과 `escapeAdmin.html`을 `index.html` 하나로 합쳐 링크를 하나로 만든다.

관리자가 조×방 단위로 제출 답안/풀이 캔버스를 확인하는 기존 기능(오늘 커밋에서 추가된 기능 포함)은 그대로 유지하고, 여기에 "이 문제는 누구 담당인지"를 이름으로 안내하는 기능을 더한다.

## 데이터 모델 변경

- `escape_data/meta/teamCount` (신규): 관리자가 명단 업로드 시 지정한 조 개수. 값이 없으면 편성 전 상태로 취급.
- `escape_data/roster/{key}`: `{name, grade, teamId, ts}` — 스키마 동일, 개인 로그인 대신 관리자 업로드로 일괄 기록. `key = sanitizeKey(name) + "_" + grade` (완전 동명이인 충돌 시 `_2`, `_3` 접미사).
- `escape_data/roster/{key}/work` 경로(개인별 풀이 캔버스 스냅샷)는 더 이상 쓰지 않는다 — 팀 단위 `submissions` 아래에 이미 캔버스가 저장되므로 중복 제거.
- `escape_data/team{N}` 진행상황 구조는 그대로, N의 범위만 1~teamCount로 동적화.

## 관리자: 명단 업로드 → 조 자동 편성 ("학생 배정" 탭)

업로드 영역을 새로 추가한다.

1. 조 개수 입력 필드.
2. 구글시트 링크 입력 + [불러오기] 버튼. 붙여넣은 URL에서 스프레드시트 ID를 정규식으로 추출해 `https://docs.google.com/spreadsheets/d/{id}/gviz/tq?tqx=out:csv` 로 CSV를 fetch한다. 이 방식은 시트 공유 설정이 **"링크가 있는 모든 사용자 - 뷰어"**여야 동작하므로, 안내 문구를 UI에 표시하고 fetch 실패 시 "시트 공유 설정을 확인해주세요" 에러 메시지를 보여준다.
3. 엑셀 파일 선택 input. SheetJS(`xlsx`, CDN: `cdn.jsdelivr.net/npm/xlsx`)로 첫 시트를 파싱한다.
4. 두 경로 모두 "학년, 이름" 2열 형식을 기대한다. 첫 행이 숫자로 시작하지 않으면 헤더로 간주하고 건너뛴다.
5. 파싱 결과는 곧바로 반영하지 않고 **미리보기 표**로 렌더링한다 — 행마다 이름/학년을 수정할 수 있는 input, 행 삭제 버튼, 그리고 "행 추가" 버튼을 둔다.
6. "이 명단으로 조 편성하기" 버튼을 누르면 confirm() 확인 후 자동 배정 알고리즘을 돌리고 `roster` 전체와 `meta/teamCount`를 한 번에 Firebase에 쓴다. (주의: 방탈출 진행 기록인 `team{N}` 데이터는 건드리지 않는다 — 완전 초기화가 필요하면 기존 "전체 초기화" 버튼을 쓴다.)

업로드 후에도 기존처럼 조별 인원 요약 표와, 학생별 수동 조 재배정 드롭다운 + 삭제 버튼은 그대로 둔다. 다만 개인별 "풀이 보기" 버튼은 제거한다 (아래 "제거되는 기능" 참고).

## 자동 조 편성 알고리즘

```
1. 명단을 학년별로 그룹화한다.
2. 각 학년 그룹 내부를 랜덤 셔플한다 (명단 순서/반 편향 방지).
3. 학년을 높은 값부터 낮은 값 순으로(6→1) 순회하면서,
   그룹의 각 학생을 "현재 배정 인원이 가장 적은 조"에 하나씩 배정한다.
4. 결과적으로 상급학년이 먼저 고르게 채워지고,
   이어서 하급학년이 그 뒤를 이어 고르게 채워진다.
```

기존 `autoAssign()` 함수와 로직 골격은 같고, 정렬 방향만 오름차순 → 내림차순으로 바꾸고 대상이 "미배정 로그인 학생"이 아니라 "업로드된 전체 명단"이 되는 점이 다르다.

## 학생 첫 화면

- 이름/학년 입력 화면(`renderNameEntry`)과 "배정 기다리는 중" 대기 화면(`renderWaiting`), 로그아웃 버튼을 제거한다.
- 앱 로드 시 로컬에 저장된 조 선택 기록이 있고 그 조가 현재 편성에 존재하면 바로 홈 화면으로 진입한다.
- 없으면 **"조를 선택하세요"** 화면을 보여준다: `teamCount`만큼 카드가 그리드로 나열되고, 각 카드에는 "N조"와 소속 학년 구성 배지(예: `6학년 2 · 5학년 1 · 4학년 1`)가 표시된다. 탭하면 그 조로 바로 입장하고 localStorage에 저장한다.
- 조가 아직 편성되지 않은 상태(`meta/teamCount` 없음)라면 "아직 조가 편성되지 않았어요"라는 안내만 보여준다.
- 화면 맨 아래에 "⚙️ 관리자 모드" 아코디언(비밀번호 입력 + 입장)을 배치한다 — 지금 홈 화면 하단에 있는 것과 같은 컴포넌트를 조 선택 화면으로 옮긴다.
- `computeTeamGrades()`는 조 선택 즉시 전체 roster를 그 조로 필터링해 계산하도록 바꾼다(개인 `safeKey`에 대한 의존 제거). `computeEffectiveGrade()`의 "조에 없는 학년은 상급학년 우선, 그다음 하급학년으로 대체" 로직은 그대로 유지한다.
- 헤더에 표시되던 "이름(학년) · N조" 텍스트는 "N조"만 남긴다.

## 관리자: 조×방 확인 화면에 "담당 학생" 안내 추가

기존 `viewTeamRoom(n, roomId)` 모달(문제별 정답/오답, 제출 답안, 풀이 캔버스, 오답 처리 버튼)은 그대로 유지한다. 여기에 문제마다 다음을 추가한다.

- 그 문제의 요구 학년을 해당 조의 보유 학년 집합과 대조해 `computeEffectiveGrade`와 동일한 규칙으로 실제 담당 학년을 구한다(학생 쪽과 로직을 공유 — 아래 "코드 공유" 참고).
- 그 학년에 해당하는 조원 이름을 roster에서 찾아 "담당: 홍길동(4학년)" 형태로 표시한다. 한 학년에 조원이 여러 명이면 모두 나열한다. 명단이 비어 있으면 "명단 없음"으로 표시한다.
- 그 밑에 지금처럼 제출 답안과 풀이 캔버스를 보여준다 (이미 팀 단위로 저장되고 있어 추가 데이터 작업 불필요).

## 파일 구조: 단일 페이지로 통합

- `escape.html` + `escapeAdmin.html`을 `index.html` 하나로 합친다. GitHub Pages 루트 링크(`https://imzerguser-cpu.github.io/escape/`) 하나로 학생/관리자 화면 모두에 접근하게 된다.
- 최상위 `appMode` 상태(`'student' | 'admin'`)로 두 화면을 토글한다. 학생 조 선택 화면의 관리자 로그인 아코디언에서 비밀번호가 맞으면 페이지 이동 없이 `appMode`를 `'admin'`으로 바꿔 같은 문서 안에서 대시보드를 렌더링한다. 관리자 화면에는 "학생 화면으로 돌아가기" 링크를 둔다.
- `sessionStorage`의 `escape_admin_ok` 플래그는 그대로 재사용(같은 탭에서는 재입력 없이 관리자 화면 재진입 가능).
- `ROOMS`, `QUESTIONS`/`QFULL`/`QMETA`, `CODES`, `FINAL_ROOM` 등 지금 두 파일에 중복 정의되어 있고 "동일해야 함"이라는 주석까지 달려 있던 상수들을 한 곳에 정의해 학생/관리자 로직이 같이 참조하게 된다 — 그동안의 동기화 실수 위험이 사라지는 부수적 이득.
- QR 인쇄용 `@media print` 규칙은 관리자 컨테이너 안에서만 스코프되며, 학생 화면 컨테이너는 인쇄 시 `display:none`이라 자연히 인쇄되지 않는다.
- 병합 후 `escape.html`, `escapeAdmin.html`은 삭제한다.

## 제거되는 기능

- 학생 개인 로그인(이름+학년 입력), 배정 대기 화면, 로그아웃 버튼.
- 관리자의 "학생별 풀이 보기"(개인 캔버스 스냅샷, `roster/{key}/work` 기반) — 팀 단위 조×방 확인 화면에 "담당 학생 안내"를 더하는 것으로 대체되어 기능 손실이 실질적으로 없음.
- 관리자의 "자동 조 편성 (미배정 학생만)" 버튼 — 명단 업로드+편성 플로우로 대체.
- 대시보드 표, 초기화 버튼 등에 흩어져 있던 "1~5" 하드코딩 — `teamCount` 기반 동적 렌더로 교체.

## 검증 계획

- 로컬에서 `index.html`을 브라우저로 열어: (1) 조가 편성되지 않은 초기 상태 안내, (2) 엑셀/구글시트 업로드 → 미리보기 → 편성 → 조 카드에 학년 구성이 정확히 반영되는지, (3) 학생이 조를 선택해 문제를 풀고 제출하면 관리자 화면에 담당 학생 이름과 함께 답안/캔버스가 뜨는지, (4) 관리자 로그인이 학생 화면 안에서 페이지 이동 없이 전환되는지, (5) QR 인쇄가 정상 동작하는지를 확인한다.
- 실제 Firebase 프로젝트(`jump-rope-43833`)에 연결된 상태이므로, 테스트 편성/제출 데이터는 검증 후 "전체 초기화" 버튼으로 정리한다.
